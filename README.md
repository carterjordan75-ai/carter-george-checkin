# Carter & George Check-In Kiosk

A modern, responsive patient check-in application for Carter & George physiotherapy clinics.

## Features

- **Clean Interface** - Elegant, minimalist design with smooth animations
- **Patient Check-In** - Simple form to collect patient name and date of birth
- **Responsive Design** - Works perfectly on tablets, phones, and desktops
- **Offline Support** - Form validation works without internet connection
- **Touch-Friendly** - Optimized for touchscreen devices
- **Virtual Reception** - Modern kiosk-style experience

## How to Use

1. **Home Screen** - Displays the Carter & George branding with a "Check In" button
2. **Click Check In** - Opens the check-in form
3. **Enter Details** - Patient enters first name, last name, and date of birth
4. **Confirm** - Submit the form
5. **Thank You** - See confirmation message "Your physio has been notified - Please take a seat"
6. **Auto Return** - Screen automatically returns to home screen after 5 seconds

## Technical Details

- **Pure HTML/CSS/JavaScript** - No dependencies required
- **Fully Self-Contained** - Single HTML file with all styling and logic included
- **Google Fonts** - Uses Cormorant Garamond and Outfit fonts
- **Dark Theme** - Professional dark gradient background with accent colors
- **Mobile Optimized** - Safe area support for notched devices

## Customization

To customize the app:

1. Change the brand name in line 501: `Carter <span class="gold-ampersand">&</span> George`
2. Add a logo: Replace the image source in line 499
3. Modify colors: Change the hex codes in the CSS (primary color: `#00a7e1`)
4. Change text: Edit the messages on various screens
5. Adjust timing: Change the 5000ms timeout on line 718 (thank you screen duration)
